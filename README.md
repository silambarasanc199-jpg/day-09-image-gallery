## 📌 Internship Task

**Day 09 – Image Gallery**

WanderGallery is a modern, responsive and interactive image gallery developed as part of my Web Development Internship task.

The project demonstrates the practical implementation of **HTML5, CSS3 Grid and JavaScript** to create a responsive gallery with filtering and an interactive lightbox experience.

## ✨ Features

- 📱 Fully responsive design
- 🖼️ 10 curated gallery images
- 🔲 CSS Grid based layout
- 🏷️ Image category filtering
- 🔍 Full-screen image preview
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- ❌ Close lightbox functionality
- ⌨️ Keyboard navigation
- 🖱️ Background-click to close preview
- 🎨 Smooth hover animations
- ♿ Accessible image alt text
- ⚡ Lazy-loaded images
- 📐 Mobile, tablet and desktop support
